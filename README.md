# Salmeron Roofing

Marketing homepage for Salmeron Roofing — a family-owned, father-and-son roofing company.

- Static site: `index.html` + `css/styles.css` + `js/main.js` + `assets/`
- Background-video hero (`assets/video/hero-720.mp4`, aerial re-roof time-lapse), real emblem logo, copper/charcoal palette.
- No build step. Open `index.html` or serve the folder.
